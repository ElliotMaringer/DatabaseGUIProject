# NFL Statistics Database System

This project is a Java-based desktop application that connects to an SQL database to manage and explore NFL player and team statistics. The graphical interface was developed using WindowBuilder, allowing users to perform specific queries and view results in a clean, interactive format.

## Project Overview

Key features of the system include:

- A full SQL backend for storing and retrieving structured NFL data
- A Java GUI (built with WindowBuilder) that supports:
  - Player and team-specific searches
  - Filtering by position, team, or season
  - Displaying statistical summaries (e.g., passing yards, touchdowns, etc.)
- Seamless integration between frontend interface and backend queries

## Tools and Technologies

- Java (Swing + WindowBuilder)
- MySQL or SQL-based RDBMS
- JDBC for database connectivity
- SQL for data manipulation and querying

## Features

- Dynamic search functionality by player name, position, or team
- SQL queries executed through GUI components (buttons, dropdowns, etc.)
- Clear, formatted display of results inside Java Swing tables or text areas
- Option to update or extend database contents through SQL scripts
